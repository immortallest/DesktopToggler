# Desktop Toggler (تاگلر دسکتاپ)

[English](README.md) | **فارسی**

با **دابل‌کلیک روی جای خالیِ دسکتاپ ویندوز**، آیکون‌های دسکتاپ *و* تسک‌بار هم‌زمان مخفی یا نمایان می‌شوند. یک «دسکتاپ تمیز» با یک حرکت، مناسب اسکرین‌شات، ضبط صفحه و ارائه.

> 🤖 **ساخته‌شده با هوش مصنوعی.** این پروژه، شامل کد منبع، تنظیمات ساخت و مستندات، توسط یک دستیار هوش مصنوعی (**Claude** از شرکت Anthropic) در گفت‌وگو با یک نگهدارندهٔ انسانی نوشته شده است. نگهدارنده آن را روی ویندوز تست کرده و گزارش داده که درست کار می‌کند، اما مجموعهٔ تست خودکار وجود ندارد. مثل هر برنامهٔ شخص ثالث، پیش از اجرا کد را بخوانید (فقط یک فایل کامنت‌دار است). بخش [اطلاعیهٔ کد تولیدشده با هوش مصنوعی](#ai-notice) را ببینید.

## امکانات

- **دابل‌کلیک روی جای خالی دسکتاپ** ← تغییر *حالت تمیز*:
  - روشن: آیکون‌های دسکتاپ مخفی + مخفی‌شدن خودکار تسک‌بار روشن
  - خاموش: آیکون‌ها نمایان + مخفی‌شدن خودکار تسک‌بار به حالت قبلی برمی‌گردد
- **نامرئی**: بدون پنجره، بدون دکمهٔ تسک‌بار، بدون آیکون سیستم‌ترِی.
- **راست‌کلیک روی دسکتاپ** ← گزینهٔ `Enable/Disable Desktop Toggler` قابلیت را روشن یا خاموش می‌کند. انتخاب شما ذخیره می‌شود و بعد از ری‌استارت هم می‌ماند.
- **همراه ویندوز بالا می‌آید** و نیازی به دسترسی ادمین ندارد (همه‌چیز به‌صورت per-user ذخیره می‌شود).
- **نصب‌کننده و حذف‌کننده در همان یک فایل EXE.** حذف‌کننده **همهٔ نسخه‌های** برنامه را پاک می‌کند (پردازش‌ها، استارتاپ، منو، تنظیمات، فایل‌ها).
- با چند مانیتور کار می‌کند (تسک‌بار همهٔ مانیتورها)، و DPI هر مانیتور را درست می‌فهمد.
- یک فایل اجرایی کوچکِ مستقل، بدون نیاز به نصب چیز دیگری. دسترسی به اینترنت ندارد.

## نصب

1. فایل `DesktopToggler.exe` را از صفحهٔ [Releases](../../releases) دانلود کنید (یا خودتان بسازید، بخش [ساخت](#ساخت)).
2. یک‌بار اجرایش کنید. برنامه:
   1. هر نسخهٔ قدیمی این برنامه را پاک می‌کند،
   2. خودش را در `%LocalAppData%\DesktopToggler\` کپی می‌کند،
   3. استارتاپ، گزینهٔ راست‌کلیک دسکتاپ و ورودی *Apps & features* را ثبت می‌کند،
   4. در پس‌زمینه شروع به کار می‌کند.

اگر برنامه از قبل نصب باشد، اجرای EXE می‌پرسد: **Yes** = نصب مجدد تمیز، **No** = حذف کامل، **Cancel** = هیچ‌کاری.

> فایل EXE **امضای دیجیتال ندارد** (امضا گواهی پولی می‌خواهد)؛ ممکن است SmartScreen در اجرای اول هشدار بدهد (*More info ← Run anyway*) و بعضی آنتی‌ویروس‌ها به هر برنامه‌ای که قلاب موس سراسری نصب کند حساس‌اند. SHA-256 فایل را با `SHA256SUMS.txt` مقایسه کنید، یا از روی کد بسازید.

## استفاده

| کار | نتیجه |
|---|---|
| دابل‌کلیک روی جای خالی دسکتاپ | تغییر حالت تمیز |
| دابل‌کلیک روی یک آیکون | رفتار عادی (تغییری ایجاد **نمی‌کند**) |
| راست‌کلیک دسکتاپ ← *Enable/Disable Desktop Toggler* | روشن/خاموش‌کردن قابلیت |

در ویندوز ۱۱ این گزینه زیر **Show more options** است (این برای همهٔ گزینه‌های برنامه‌های غیرمایکروسافتی صدق می‌کند).

معمولاً بعد از روشن‌شدن مخفی‌سازی خودکار، تسک‌بار کمی دیرتر پایین می‌رود و با خاموش‌شدنش فوراً برمی‌گردد. این زمان‌بندی را Explorer ویندوز تعیین می‌کند، نه این برنامه.

## حذف

هر کدام از این‌ها **همهٔ نسخه‌های** برنامه را پاک می‌کند:

- *Settings ← Apps ← Desktop Toggler ← Uninstall*
- اجرای `DesktopToggler-Uninstall.exe` (یا هر کپی از EXE که اسم فایلش شامل `uninstall` باشد)
- خط فرمان: `DesktopToggler.exe --uninstall` (با `--silent` بدون پیام)

اگر برنامه در حالت تمیز مانده باشد، حذف‌کننده اول آیکون‌ها و تسک‌بار را به حالت عادی برمی‌گرداند. فایلِ در حال اجرا نمی‌تواند خودش را پاک کند؛ پس چند ثانیه بعد از بسته‌شدن حذف‌کننده، یک `cmd.exe` مخفی پوشهٔ باقی‌مانده را پاک می‌کند. کپی‌هایی که خودتان جای دیگری گذاشته‌اید (مثلاً *Downloads*) را باید دستی پاک کنید.

### آرگومان‌های خط فرمان

| آرگومان | معنی |
|---|---|
| *(بدون آرگومان)* | کپی نصب‌شده: اجرا در پس‌زمینه. کپی دیگر: نصب / نصب مجدد |
| `--install` | نصب اجباری (بدون پرسش) |
| `--uninstall` | حذف همهٔ نسخه‌ها |
| `--silent` | بدون هیچ پیامی |
| `--toggle-enabled` | داخلی: توسط گزینهٔ منوی راست‌کلیک استفاده می‌شود |

## طرز کار

1. **نصب.** EXE خودش را به `%LocalAppData%\DesktopToggler\` کپی می‌کند و چند کلید رجیستری per-user می‌نویسد (بخش [رجیستری و فایل‌ها](#registry)).
2. **شنونده.** هنگام ورود به ویندوز، کپی نصب‌شده اجرا می‌شود، یک پنجرهٔ نامرئی از نوع *message-only* می‌سازد و یک **قلاب موس سطح‌پایین** (`WH_MOUSE_LL`) نصب می‌کند.
3. **تشخیص دابل‌کلیک.** قلاب دابل‌کلیک را با همان قواعد خود ویندوز تشخیص می‌دهد (`GetDoubleClickTime` و `SM_CXDOUBLECLK/SM_CYDOUBLECLK`). بعد از هر دابل‌کلیک، ۷۰۰ میلی‌ثانیه «فاصلهٔ ایمنی» هست تا یک کلیک اضافهٔ سریع، تغییر دومی راه نیندازد که اولی را خنثی کند. خودِ قلاب کار واقعی نمی‌کند و فقط مختصات کلیک را به یک نخ کارگر می‌دهد، چون ویندوز قلاب‌های کند را قطع می‌کند.
4. **آیا جای خالی دسکتاپ است؟** نخ کارگر می‌پرسد زیر نشانگر چه پنجره‌ای است و تا پنجرهٔ سطح‌بالای آن بالا می‌رود. اگر دسکتاپ بود (`Progman` یا `WorkerW`) کلیک حساب می‌شود. اگر روی فهرست آیکون‌ها (`SysListView32`) خورده باشد، پیام `LVM_HITTEST` به فهرست آیکون Explorer فرستاده می‌شود تا معلوم شود نشانگر روی یک آیکون است یا جای خالی. وقتی آیکون‌ها مخفی‌اند فهرست نامرئی است و کلیک روی دسکتاپ به‌تعریف جای خالی است.
5. **مخفی/نمایان‌کردن آیکون‌ها.** همان دستوری فرستاده می‌شود که خود Explorer برای *View ← Show desktop icons* استفاده می‌کند: `WM_COMMAND` با شناسهٔ دستور `0x7402` به پنجرهٔ `SHELLDLL_DefView` دسکتاپ. موفقیت با بررسی (نا)مرئی‌شدنِ فهرست آیکون‌ها تأیید می‌شود. اگر دستور اثر قابل‌مشاهده‌ای نداشت، فهرست مستقیم نمایش یا مخفی می‌شود (راه جایگزین)، پس نتیجهٔ دیداری همیشه درست است.
6. **تسک‌بار.** مخفی‌شدن خودکار با API مستندِ AppBar (`SHAppBarMessage` با `ABM_GETSTATE` و `ABM_SETSTATE`) برای تسک‌بار اصلی و تسک‌بار هر مانیتور دیگر تغییر می‌کند. تنظیم قبلی ذخیره می‌شود و هنگام خروج از حالت تمیز برمی‌گردد.
7. **فعال/غیرفعال.** گزینهٔ منو دستور `DesktopToggler.exe --toggle-enabled` را اجرا می‌کند. این پردازش کوتاه‌عمر یک پیام خصوصی به شنونده می‌فرستد؛ شنونده تنظیم را برعکس می‌کند، برچسب منو را به‌روز می‌کند و قلاب موس را نصب یا برمی‌دارد. «غیرفعال» یعنی اصلاً قلاب نصب نیست.

## توضیح کد

همهٔ منطق در [`src/DesktopToggler.cpp`](src/DesktopToggler.cpp) است (Win32 API خالص، C++17، بدون کتابخانهٔ بیرونی).

| بخش | توابع |
|---|---|
| ورودی / حالت‌ها | `wWinMain` و `EnableDpiAwareness` — آرگومان‌ها را می‌خواند؛ اسم فایلی که شامل `uninstall` باشد هم حالت حذف را انتخاب می‌کند |
| قلاب موس | `MouseProc` (زمان‌بندی دابل‌کلیک، فاصلهٔ ایمنی، محافظ مشغول‌بودن)، `InstallHook`، `RemoveHook` |
| نخ کارگر | `WorkerProc` ← `HandleDoubleClick` ← `HitTestDesktopIcon` (`LVM_HITTEST` بین‌پردازشی با `VirtualAllocEx`/`WriteProcessMemory`) |
| آیکون‌های دسکتاپ | `FindDefView`، `FindDesktopListView`، `AreIconsHidden`، `SendIconsCommand`، `SetIconsHidden` |
| تسک‌بار | `GetTaskbarAutoHide`، `SetAutoHideOne`، `SetTaskbarAutoHide` |
| وضعیت | `ToggleCleanMode` (جهت تغییر را تعیین می‌کند و تنظیم قبلی مخفی‌سازی خودکار را به خاطر می‌سپارد) |
| فعال/غیرفعال | `UpdateContextMenu`، `ToggleEnabledFeature`، `HelperToggleEnabled`، `WndProc`، `RunListener` |
| نصب‌کننده | `DoInstall`، `RegisterUninstallEntry`، `RunInstallerInteractive` |
| حذف‌کننده | `DoUninstall`، `RemoveAllVersions`، `StopAllInstances`، `FindTrace*`، `DeleteTree`، `ScheduleDelayedDelete`، `RestoreDesktopIfWeChangedIt` |
| عیب‌یابی | `Logf` (فایل لاگ با سقف حجم) |

نکات طراحی:

- **پاک‌سازی «همهٔ نسخه‌ها»** بر پایهٔ پیشوند `DesktopToggle` انجام می‌شود (نام پردازش‌ها، ورودی‌های استارتاپ، کلیدهای منو، کلیدهای تنظیمات، پوشه‌های نصب). ورودی‌های استارتاپ از روی *خط فرمانشان* هم شناسایی می‌شوند، پس ورودی تغییرنام‌داده هم پیدا می‌شود. پردازش‌های لجوجِ قدیمی که `WM_CLOSE` را نادیده می‌گیرند بعد از یک انتظار کوتاه بسته می‌شوند.
- **به وضعیت کورکورانه اعتماد نمی‌شود.** بعد از اولین تغییرِ موفق و مشاهده‌شده، برنامه پیش از هر تغییر وضعیت واقعی آیکون‌ها را می‌خواند؛ پیش از آن از پرچم خودش استفاده می‌کند.
- **بدون دسترسی ادمین**: فقط `HKCU` و `%LocalAppData%` لمس می‌شوند و مانیفست `asInvoker` می‌خواهد. (اجرا با دسترسی بالا حتی ارتباط با Explorerِ معمولی را سخت می‌کند.)
- **آگاهی از DPI هر مانیتور** (مانیفست) مختصات صفحه را با Explorer هماهنگ نگه می‌دارد؛ این برای تشخیص آیکون روی نمایشگرهای بزرگ‌نمایی‌شده مهم است.

<a id="registry"></a>

### رجیستری و فایل‌ها

| محل | کاربرد |
|---|---|
| `HKCU\Software\DesktopToggler` | `Enabled`، `PrevAutoHide`، `CleanActive` |
| `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` ← `DesktopToggler` | اجرای خودکار |
| `HKCU\Software\Classes\DesktopBackground\Shell\DesktopToggler` (و `\command`) | گزینهٔ راست‌کلیک دسکتاپ |
| `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\DesktopToggler` | ورودی *Apps & features* |
| `HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced\HideIcons` | فقط خواندنی، جایگزین وقتی Explorer هنوز آماده نیست |
| `%LocalAppData%\DesktopToggler\DesktopToggler.exe` | برنامهٔ نصب‌شده |
| `%LocalAppData%\DesktopToggler\log.txt` | لاگ تشخیصی (حداکثر ۱۲۸ کیلوبایت) |

## ساخت

هدف: ویندوز x64. هر کدام از روش‌های زیر کافی است.

### GitHub Actions (بدون ابزار محلی)

ورک‌فلوی [`.github/workflows/build.yml`](.github/workflows/build.yml) با هر push و pull request می‌سازد:

1. **Actions ← Build ← (آخرین اجرا) ← Artifacts ← DesktopToggler** را باز کنید و فایل‌های EXE را دانلود کنید.
2. برای انتشار Release، یک تگ push کنید:

</div>

```
git tag v2.0.0
git push origin v2.0.0
```

   ورک‌فلو می‌سازد و `DesktopToggler.exe`، `DesktopToggler-Uninstall.exe` و `SHA256SUMS.txt` را به یک GitHub Release جدید پیوست می‌کند.

### لینوکس / macOS / WSL (کامپایلر متقاطع mingw-w64)

```bash
sudo apt-get install g++-mingw-w64-x86-64   # Debian / Ubuntu
bash build.sh                               # خروجی در dist/
```

## عیب‌یابی

- **آیکون‌ها یا تسک‌بار واکنش نشان نمی‌دهند**: فایل `%LocalAppData%\DesktopToggler\log.txt` را باز کنید. برای هر دابل‌کلیک روی دسکتاپ می‌نویسد چه چیزی لمس شد، تست آیکون چه برگرداند و کدام روش تغییر جواب داد. آن را به [گزارش خطا](../../issues/new/choose) پیوست کنید. لاگ فقط رویدادهای خود برنامه را دارد (نه کلیدهای صفحه‌کلید، نه نام فایل‌ها).
- **تسک‌بار با تأخیر پنهان می‌شود**: عادی است، بخش [استفاده](#استفاده).
- **گزینه در منوی راست‌کلیک ویندوز ۱۱ نیست**: زیر *Show more options* را ببینید.
- **هشدار آنتی‌ویروس / SmartScreen**: بخش [نصب](#نصب).

## محدودیت‌ها

- فقط ویندوز ۱۰ و ۱۱ روی x64 (نسخهٔ ARM64 یا ۳۲ بیتی ارائه نمی‌شود).
- ویندوز API مستندی برای مخفی‌کردن آیکون‌های دسکتاپ ندارد؛ این برنامه از همان دستوری استفاده می‌کند که خود Explorer به کار می‌برد (`0x7402`) و نتیجه را بررسی می‌کند، با راه جایگزین. یک به‌روزرسانی آیندهٔ ویندوز می‌تواند این رفتار را تغییر دهد.
- منوی راست‌کلیک سطح‌اولِ ویندوز ۱۱ را برنامهٔ بسته‌بندی‌نشده نمی‌تواند استفاده کند.
- فقط از HKCU و LocalAppData استفاده می‌شود، پس برنامه per-user است.
- روی همهٔ نسخه‌های ویندوز تست نشده و تست خودکار ندارد.

## اطلاعیهٔ کد تولیدشده با هوش مصنوعی

این مخزن توسط **Claude** (مدل هوش مصنوعی ساختهٔ Anthropic) و با همکاری یک نگهدارندهٔ انسانی تولید شده است؛ او قابلیت‌ها را خواسته، برنامه را روی یک ویندوز واقعی اجرا کرده و نتیجه را گزارش داده است. نسخه‌های اول درست کار نمی‌کردند؛ گزارش‌های نگهدارنده (و یک بازنویسی) به طراحی فعلی رسید. منطق نصب و حذف علاوه بر آن زیر Wine روی «نسخه‌های قدیمیِ» ساختگی آزمایش شده است؛ رفتار آیکون‌ها و تسک‌بار را نگهدارنده دستی بررسی کرده است.

کدِ نوشته‌شده توسط هوش مصنوعی ممکن است اشتباه داشته باشد. توصیه می‌شود `src/DesktopToggler.cpp` را بخوانید، خودتان EXE را بسازید و مشکلات را گزارش کنید.
